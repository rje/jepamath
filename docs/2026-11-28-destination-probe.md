# Can a single mid-carry movie identify the destination?

The two seed-0 continuations reached similar absolute ending accuracy despite strong within-scene ordering. The new diagnostic freezes the control and treatment checkpoints at 100k additional updates. It tests whether a simple supervised readout of a single RGB prefix can generalize to new layouts and whether the native predictor uses the available information.

## Design fixed before model scoring

Use 64 fit layouts and 128 independent test layouts. Each split has an equal number of layouts for one versus two starting cylinders and a hopper on the left versus right. For each layout, render a return to the hopper, an incoming placement in the box, and a shuffle inside the box. Movies share the starting stock. The first two share the grasp and the first 12 frames. Check that the carried object is airborne at frame 16, that the two paths have visibly diverged, that the physical release occurs later, and that the expected inventory is present after landing. Candidate endings use independently jittered versions of the same sites, four per count. The scorer compares the starting count with one more object on every trial. Consequently these are conditional ending choices and do not establish exact counting. The stored arm names, scene identifiers and geometry never enter the fitted readout.

The primary comparison uses the two common-pickup movies. Each movie gets a separate prediction. A secondary comparison uses the incoming placement and the box shuffle, matching the previous primary endpoint. Fit a separate linear logistic readout for each arm, task and input condition, using a fixed regularization setting and four spatially pooled quadrants of the encoder's last observed tubelet. Fit the scaler and readout only on fit layouts. Keep the established frozen ending score, candidate bank and hopper mask for comparison. Evaluate four-frame pre-action input, 16-frame mid-carry input, the final carry frame repeated 16 times, and 24-frame after-landing input. Use the revealed ending as a positive control. Intervals resample entire test layouts and differences are paired.

Report absolute accuracy, both route accuracies and the conditional scores by start and tray side. Report the probe advantage over native choice and the movie advantage over the independently trained still-frame probe. A strong still-frame result indicates usable information in a single image; an incremental motion claim requires a positive paired lower bound versus still. Treat pre-action accuracy deviating from 50% on identical histories as an implementation defect. An unreliable revealed-ending control limits interpretation of the native score. A reliable probe advantage with weak native choices prioritizes predictor/readout analysis. Weak probe performance leaves both representation quality and the limited linear readout as explanations. Visible forecasting that clears the prior 60% lower bound on both route outcomes across fresh layouts motivates a one-hidden-transfer test; examine the count and tray-side breakdown before advancing. All reported 95% intervals are descriptive, without multiplicity adjustment.
